# LOGIC

Personal portfolio website showcasing my frontend development work.

## Project Structure

- frontend/ — React application
- backend/ — Django REST API

## Frontend

- React
- Redux Toolkit
- React Router
- Tailwind CSS
- Vite

## Backend

- Python
- Django
- Django REST Framework
- SQLite / PostgreSQL

## Development

Frontend:

```powershell
cd frontend
npm install
npm run dev
```

Backend:

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
